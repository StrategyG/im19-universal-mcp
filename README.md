# IM19 Universal MCP — Intelligent Mind 19

Institutional Model Context Protocol integration gateway, developed with security-first and evidence-first controls.

**Development status:** Phase 1–3 in progress. This repository does **not** imply that ChatGPT, Google OAuth, or YouTube live access is connected.

The protected `main` baseline is initialized here; implementation is developed on a separate feature branch and reviewed through a pull request.

## Architecture
ChatGPT MCP client → remote MCP gateway → policy / identity boundary → provider adapters → official APIs.

See the implementation branch and Pull Requests for source, tests, deployment notes and limitations.
